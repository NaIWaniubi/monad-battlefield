# COST · 实账表(每一格值多少钱,每一场要多少钱)

> 原则:本文只有两种数——**实测**(标"实测")与**由实测单价×数量的算术**(标"算术")。凡链上可查的数都能被 DevRel 当场开浏览器戳穿,所以宁窄勿宽。单价与结论口径与 README「Measured vs target」表一致。

## 1. 单价:0.0066 MON/笔(实测)

```
单笔 claim = gasLimit × gasPrice = 60,000 × 110 gwei = 0.0066 MON
```

- **按 gasLimit 计费**:Monad 回执实测 `gasUsed == gasLimit`(README.md:55)——gasLimit 给多了是白烧,给少了 revert 照扣:实测 `gasLimit=50,000 → 0/3 成功;60,000 → 3/3`;单笔 45,000 偶尔过,批量成功率≈0,**信批量统计不信运气**(RUNBOOK.md:77-80)。
- **gasPrice 110 gwei**:链上 baseFee ≈100 gwei,110 最稳(RUNBOOK.md:81;兜底常量 `FALLBACK_GAS_PRICE=110_000_000_000n`,index.mjs:951)。
- 车道统一 **legacy + 显式 gasPrice**;type-2 在公共测试网实测不稳定,日志无被拒原始错误串存档,故不作强断言(README.md:56)。
- revert 也扣钱 ⇒ **被拒的点击是否上链,直接决定这场是烧 gas 还是烧 CPU**(服务端 429 拦下的 `cooldown_3s` 一克不烧,对照 #363 式合约冷却照扣,index.mjs:72-79)。

## 3. 中继 8 key 的产能墙(费率墙 + 速率墙叠加,取小者)

- **配置**:默认 `RELAYER_COUNT=8`(index.mjs:57),每 key 独立 nonce 队列、不 await receipt(:1090-1093)——**发送侧不是瓶颈**。
- **速率墙(链的物理)**:余额 <10 MON 的 EOA 被 Monad reserve-balance 规则限到 1 tx/3 块 ≈ **0.83 tx/s/key**(README.md:47,EVIDENCE.md:37)。⇒ 8 key 且每 key 都是小余额时,**观众代付通道的实际产能 ≈ 8×0.83 ≈ 6.6 tx/s(算术)**——318 笔的一场在时间上摊得开(静默墙 240 笔经 420 ms 提交后,入块以块计),但**不要**把 8-key 中继当成 80 tx/s 蜂群用:那是 40 道×2 tps 的蜂群配置,且同样被这堵墙压住(实测 17 道峰值 16 tx/s,README.md:58)。
- **费率墙(钱)**:每 key 注资 ≥0.27 MON 只覆盖 318 笔;蜂群 `FUND_MON` 默认 0.05/道 = **7.5 笔/道**(RUNBOOK.md:175,老配置第 61 人 502 穿帮的教训,C4-redteam.done 杀 4)。
- **人侧闸门(不是链墙)**:`rate_limited` 每 clientId 6 笔/10 s、`too_many` 每 IP 30 笔/10 s(index.mjs:60-69,1589-1615)——真人点不到,脚本洪峰撞这里。
- 撞墙自愈:没 gas 的 key 停用、补币 ≤30 s 自动恢复不重启(index.mjs:779-783,1252-1271);节点接受数与落链数分开看:`budget.mjs` 是上台第 0 步(README.md:80,RUNBOOK.md:221)。

## 4. 双墙模型:**费墙 ≠ 储备墙**

| | 费墙(会花掉) | 储备墙(躺着不动) |
|---|---|---|
| 是什么 | 每笔 0.0066 MON,从余额扣 | 余额 <10 MON/道 → 该道被限 0.83 tx/s |
| 想演 90 s @80 tx/s | 7,200 笔 ≈ **47.5~48 MON** | 40 道 × 10 MON = **400 MON 趴在车道上** |
| 出处 | README.md:86,89;RUNBOOK.md:137 | README.md:47,60;RUNBOOK.md:83,137 |

"钱花了"和"钱在账上"是**两个都必要的前提**;只带 48 MON 上场,40 条道每条分 1.2 MON,照样全员 0.83 tx/s,顶到 ~33 tx/s 封顶(40×0.83,算术,RUNBOOK.md:144)。`GAP_MS` 调小没有用——间隔不是瓶颈,储备才是(RUNBOOK.md:118)。

| 档位 | 构成(费+储) | 能演什么 | 台上话术(必须照顶栏) |

## 6. L1 反事实(按 README 现口径,不越界)

```
配置目标:80 tx/s × 60,000 = 4.8 Mgas/s  vs  L1 ~30 Mgas/12 s ≈ 2.5 Mgas/s → 装不下,不解释。
实测峰值:16 tx/s × 60,000 = 0.96 Mgas/s → 低于 gas 墙,纯容量主网塞得下。
90 秒账单:48,000 笔 × 60,000 = 2.88e9 gas,按我们同一个 110 gwei ≈ **316.8 ETH**(VITE_ETH_PRICE=3000 → **≈ $950k**)。
体验墙:L1 持续 ~15 tx/s,"点了就亮"要抢 fee-market + ~12 s 确认等待 —— 墙是价格和延迟,不是区块装不进。
```
